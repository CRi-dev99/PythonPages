Setup

Install Python

Download Python

Go to the official Python downloads page and choose the latest stable version for your computer.

Open the official Python downloads page

Windows setup

  • Download the Windows installer from python.org.
  • Open the installer.
  • Tick Add python.exe to PATH before installing.
  • Click Install Now.
  • If you see Disable path length limit at the end, click it.

The Python documentation also explains Windows installation and the Python install manager.

Open the official Python on Windows documentation

Check it worked

Open PowerShell or Command Prompt and type:

python --version

If that does not work on Windows, try:

py --version

On macOS, you may need:

python3 --version

Run a first program

Create a file called hello.py and type:

print("Hello, Python")

Then run it from the same folder:

python hello.py

On macOS, use:

python3 hello.py

You should see:

>>> Hello, Python

Set up VS Code

  • Install Visual Studio Code.
  • Open the Extensions tab.
  • Install the extension called Python by Microsoft.
  • Open your Python folder in VS Code.
  • Open a .py file and choose a Python interpreter if VS Code asks.

The VS Code Python docs explain that you need both Python itself and the Python extension.

Open the official VS Code Python documentation

Common problems

  • If python is not recognised, close and reopen your terminal.
  • If it still is not recognised on Windows, reinstall Python and tick Add python.exe to PATH.
  • If VS Code cannot find Python, use Python: Select Interpreter from the Command Palette.
