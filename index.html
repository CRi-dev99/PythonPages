Learn Python one clear step at a time.

This tutorial website is a simple starting point for learning Python. Use the sidebar to switch between guided tutorial topics and practical coding challenges.

The tutorials introduce the core ideas: input, variables, decisions, loops, lists, and functions. Each topic is designed to be short enough to follow during class and useful enough to practise straight away.

When you are ready to test yourself, switch the sidebar to challenges and try building a complete program from a brief.
